
# EduMetric – Academic Performance Management System

## About the Project

EduMetric is a full-stack web application independently developed to help students calculate their GPA, monitor academic performance, and plan their future academic goals.

The application not only helps students understand their current academic performance but also motivates them to work towards their desired GPA by planning their future academic results.

## Key Features

- **GPA Calculation:** Calculate GPA based on academic results.
- **Academic Performance Tracking:** Monitor academic progress.
- **Future GPA Planning:** Understand the GPA required in future semesters to achieve academic goals.
- **Student Motivation:** Help students set academic targets and stay motivated to achieve them.

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- MongoDB

### 1. Clone the Repository

```bash
git clone https://github.com/tharushikadilrukshi111-hash/EduMetric-.git
cd EduMetric-
```

### 2. Setup the Backend

```bash
cd backend
npm install
```

Configure the required environment variables in a `.env` file according to your backend configuration.

Start the backend using the appropriate script in `package.json`.

### 3. Setup the Frontend

Open another terminal:

```bash
cd frontend
npm install
```

Start the frontend using the appropriate script in `package.json`.
